        Add Backpocket to the iPhone share sheet

        iPhone doesn't let web apps join the share sheet directly, so a free Apple Shortcut does it. Set it up once, then tap Share → Backpocket in Instagram, TikTok, YouTube or anywhere else.

        Quickest: get the ready-made Shortcut, tap “Add Shortcut”, and you're done.

        Or build it yourself (about 2 minutes):

        1. Open the Shortcuts app and tap + to make a new shortcut. Tap ⓘ in the bottom bar and turn on Show in Share Sheet.
        2. A Receive … from Share Sheet block appears at the top. Tap its blue input types and make sure URLs and Text are on (leaving the rest on is fine; it then reads “Apps and 18 more”). Leave If there’s no input on Continue.
        3. Search for Get URLs from Input and add it. It should read Get URLs from Shortcut Input.
        4. Add If and set the condition to URLs does not have any value. Inside it, add Text and insert the Shortcut Input variable (the shared text itself).
        5. Under Otherwise, add another Text and insert the URLs variable.
        6. Below End If, add URL Encode and set its input to If Result.
        7. Add Open URLs with: [URL Encoded Text]
        8. Tap the name at the top, choose Rename and call it Backpocket, then Choose Icon to pick one.

        Good to know: the Shortcut opens Backpocket in Safari. iPhone keeps a home-screen app's storage separate from Safari's, so sign in to Backpocket in Safari too - then links saved from the share sheet sync to the same account as your home-screen app.

        Your account isn't on the shared AI list, but you can use AI with your own free key from Google.

        1. Open Google AI Studio → API keys and sign in.
        2. Create a key (the free tier is fine) and copy it.
