          Add Backpocket to the iPhone share sheet

          iPhone doesn't let web apps join the share sheet directly, so a free Apple Shortcut does it. Set it up once, then tap Share → Backpocket in Instagram, TikTok, YouTube or anywhere else.

          Quickest: get the ready-made Shortcut, tap “Add Shortcut”, and you're done.

          Or build it yourself (about 2 minutes):

          1. Open the Shortcuts app → + (New Shortcut). Tap the ⓘ details button and turn on Show in Share Sheet. Set it to receive URLs and Text.
          2. Add the action Get URLs from Input. Then add If “URLs” does not have any value → Text with the Shortcut Input (the shared text itself); Otherwise → the URLs; End If.
          3. Add URL Encode and pass it the result of the If.
          4. Add Open URLs with: [URL Encoded Text]
          5. Name it Backpocket and pick an icon.

          Good to know: the Shortcut opens Backpocket in Safari. iPhone keeps a home-screen app's storage separate from Safari's, so sign in to Backpocket in Safari too - then links saved from the share sheet sync to the same account as your home-screen app.

          Use your own Gemini key

          Your account isn't on the shared AI list, but you can use AI with your own free key from Google.

          1. Open Google AI Studio → API keys and sign in.
          2. Create a key (the free tier is fine) and copy it.
          3. Paste it below.

          The key is stored only on this device, in this browser. AI calls go straight from here to Google - never through Backpocket's server, and never using anyone else's quota.
